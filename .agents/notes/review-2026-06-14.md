## Findings

### 1. Missing `libexec/align` runtime route

`align` is listed as a public command in:

- `references/specification.md`
- `references/specification/commands.md`
- `README.md`
- `bin/tilde help` output

The command relationship documents `align = internal.align`. However, `libexec/` contains no `align` implementation:

```text
apply   boot   checkout   doctor   help   plan   preflight   smoke   ssh   status   sudo
```

The spec says public commands are agent-orchestrated unless a matching runtime route is explicitly defined, so the current state is spec-compliant. In practice, agents currently generate an `align` plan via `bin/tilde plan --mode align` and apply it with `bin/tilde apply`, which works.

If `align` should remain agent-orchestrated, consider making `bin/tilde align` fail with a clear message rather than a generic route-not-found error. If it should become runtime-driven, add `libexec/align` and wire it through the router.

## Resolution

`libexec/align` is implemented and routed through `bin/tilde align`. It generates `--mode align` plans for configured or explicit local repositories and applies them through `bin/tilde apply`.
